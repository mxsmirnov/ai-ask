# Итеративная разработка Y-Statement Agent Skill

Набор показывает развитие одного Agent Skill небольшими изменениями.

## Принцип

v0.1 самодостаточна и содержит формат ADR прямо в `SKILL.md`.

Начиная с v0.2 структура ADR вынесена в `assets/adr-template.md`: раздел `Формат` в `SKILL.md` только указывает использовать этот файл и объясняет заполнение `{tasks_section}`. Сам шаблон Y-Statement в `SKILL.md` больше не дублируется.

После v0.2 следующие версии дописывают новые возможности, не переписывая уже существующие секции.

## Версии

| Версия | Изменение |
|---|---|
| v0.1 | Минимальная генерация ADR со встроенным форматом |

## Основные правила

Y-Statement содержит шесть частей в порядке:

`В контексте` → `сталкиваясь с` → `мы решили` → `и отвергли` → `чтобы` → `принимая`.

Если данных для части нет, используется `—`. Для каждого `—` создаётся задача в `## Задачи на доработку`. При полном Y-Statement секция задач отсутствует. Недостающие сведения не выдумываются.
