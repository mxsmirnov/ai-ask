# Приложение / система — app

## Смысл

Информационная система, которую затрагивает изменение. Термины «приложение» и «система» в этой предметной области обозначают одно понятие.[^email-01]

Страница описывает сущность контекста [app](context.md). Отдельный агрегат для системы на этом этапе не выделен.

## Сведения и связи

- Идентификатор системы — для ссылок между контекстами.[^email-02]
- Владелец — [подразделение](../change/org-unit.md), которое несёт организационную ответственность за систему.[^email-01]
- Затрагивающие систему [RFC](../change/rfc.md) — запросы на изменение.
- [Релизы](release.md) — выпуски, в рамках которых реализуются изменения в системе.[^email-01]

## Правила из источников

У каждой системы должен быть определён владелец. Инициатор изменения может отличаться от владельца системы. Одно изменение может затрагивать несколько систем. Сведения о системе должны сохраняться независимо от отдельных запросов.[^email-01]

## Предложение по ответственности

Алиса предлагает вести систему и назначение её владельца в `app`, а сведения о самом подразделении — в `change`. Для связи используются идентификаторы.[^email-02]
