# Учебный пример OKF и DDD — редакция 5

- `shop-wiki/` — корень OKF v0.2; начните с `shop-wiki/index.md`.
- `schema/aggregate.md` и `schema/bounded-context.md` — два русских Markdown-шаблона с OKF frontmatter. `template_for` — наше расширение, не стандартное поле OKF.
- `raw/shop-story.md` — простой исходный рассказ без frontmatter, вне OKF-бандла.
- `HISTORY.md` — единая хронология создания и изменений. Время вымышлено, Москва UTC+03:00.

Внутри wiki ссылки `/...` относительны корню бандла, а не корню сайта. Каталоги `schema/` и `raw/` находятся рядом с `shop-wiki/`. Шаблоны не входят в историю создания предметных страниц. Ссылки на schema и raw используют файловый относительный путь; для переноса источников сохраняйте весь архив. Единый `shop-wiki/index.md` перечисляет все содержательные страницы, а `shop-wiki/log.md` хранит всю историю от новых записей к старым. В подкаталогах контекстов навигацию по смыслу обеспечивают `context.md` без локальных индексов и журналов.

Предметные правила придуманы для примера. `status: stable` означает готовность к чтению в учебной модели, не реальную экспертную верификацию. Неизмеренные показатели явно помечены как оценки. Сведения sources в canvas-страницах различают источник структуры и исходный рассказ.

Источники структуры: [Aggregate Design Canvas](https://github.com/ddd-crew/aggregate-design-canvas) и [Bounded Context Canvas](https://github.com/ddd-crew/bounded-context-canvas), DDD Crew и участники проектов; просмотрены 28.09.2026.
