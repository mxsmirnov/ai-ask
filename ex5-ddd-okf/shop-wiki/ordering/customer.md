# Определение

Покупатель — лицо, указанное при оформлении [заказа](/ordering/order.md). У него есть локальный идентификатор в Ordering и контакт для уведомлений.

# Граница смысла

Покупатель не обязан сам оплачивать заказ. В [Billing](/billing/context.md) для этой роли существует отдельное понятие [плательщика](/billing/payer.md); сопоставление описано на [карте контекстов](/context-map.md).
